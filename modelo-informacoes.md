## Fotos

Salve as fotos na pasta do cliente com estes nomes (jpg, png ou webp, a maior resolução que tiver). Foto que não existir, não mande: o site reserva o espaço.

| Arquivo | O que mostrar |
|---|---|
| `logo` | Logo (de preferência PNG com fundo transparente) |
| `hero` | Telhado com placas, foto larga e de dia (drone ou do alto) |
| `antes` | Telhado antes da instalação |
| `depois` | O mesmo telhado depois, mesmo ângulo da foto `antes` |
| `passo-visita` | Técnico avaliando um telhado ou o padrão de entrada |
| `passo-projeto` | Projeto na tela, proposta impressa ou reunião com cliente |
| `passo-instalacao` | Equipe fixando placas no telhado |
| `passo-homologacao` | Inversor instalado ou medidor novo |
| `obra-1` a `obra-6` | Obras entregues (a `obra-1` é a mais bonita) |
| `equipe` | Equipe, de preferência uniformizada numa obra |
| `responsavel` | Retrato do responsável técnico |
| `final` | Equipe no telhado terminando uma instalação |

Fotos com outros nomes também servem: a skill olha cada uma e escolhe o espaço, só leva mais tempo.
